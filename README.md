# Blog Website Using Django

Welcome to the **Blog Website** repository! This project is a fully functional blog website built using the Django framework. It provides features like user authentication, blog post creation, editing, and deletion and a responsive design using HTML templates.

## Features

- User authentication (Sign up, Login, Logout)
- Create, edit, and delete blog posts
- Interactive UI built with Django templates and HTML
- Responsive design for mobile and desktop users
- Organized structure for scalability and maintainability

## Technologies Used

- **Backend**: Django (Python)
- **Frontend**: HTML, CSS
- **Database**: SQLite (default Django database)
- **Other**: JavaScript, Bootstrap (optional for styling)
